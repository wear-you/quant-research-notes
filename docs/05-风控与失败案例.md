# 05 · 风控、成本与失败案例

> 来源：子 agent 调研（🔁二手）。标注"自算"的为子 agent 自行计算，**未复核**。
> 这一章是公开材料最缺失的部分——99% 的内容讲"怎么赚"，这一章讲"钱怎么没的"。

## 一、成本：先于收益存在的确定性损失

### A 股显性费用（📄法规级，可信）

| 项 | 数值 | 备注 |
|---|---|---|
| 佣金 | 名义万 2.5，**单笔最低 5 元**，上限 3‰ | 最低 5 元是散户最大的隐性漏损 |
| 印花税 | **卖出单边 0.05%**（2023-08-28 减半） | 买入不收；ETF 免 |
| 过户费 | 0.001% 双向 | 沪深北统一 |

**关键算例**：1 万元单笔——买入佣金 5 元 = 5bp（名义仅 2.5bp），卖出佣金 5 元 + 印花税 5 元 = 10bp。**往返约 15bp**。
→ 单笔 <2 万元时，最低佣金把实际费率抬高一倍。**回测必须按"每笔最低 5 元"建模，不能只按费率。**

### A 股隐性成本（价差 + 冲击）

上交所价格冲击指数（2023 报告）：10 万元 **15–16bp**、25 万元 23–24bp、90 万元 50–52bp。

**拟合曲线（子 agent 自算）**：
```
cost(Q) ≈ 15.5bp × √(Q / 10万元)
```
| 下单金额 | 拟合 | 实测 | 偏差 |
|---|---|---|---|
| 10 万 | 15.5bp | 15–16bp | 基准 |
| 25 万 | 24.5bp | 23–24bp | +0.5~1.5 |
| 90 万 | 46.5bp | 50–52bp | -3.5~-5.5（大单额外冲击） |

> **一条公式就能算出"多少钱以上不该做"。**

### 加密成本

- 现货 0.10%/边（BNB 抵扣 0.075%）；合约 maker 0.02% / taker 0.05%
- **永续资金费 0.01%/8h ≈ 11%/年起步**，极端行情可到 >100% 年化
- 滑点实测（2026-11）：$1k 以内 ≈0.01bp，$1M BTC 现货约 2.1bp，山寨币 $100k 就 1–1.5bp

### 换手是隐形费率

按往返 0.40%（佣金 5bp + 印花 5bp + 冲击 30bp）：
- 年换手 30 倍 → **12%/年**
- 年换手 50 倍 → **20%/年**

**我们自己的实测印证了这条**：A 股 VOLT 组合换手 977%/年，8bp 成本吃掉 0.78pp，20bp 吃掉 1.95pp——这就是为什么成本从 8bp 提到 20bp 策略就崩。

## 二、仓位：凯利公式的真相

子 agent 自算（p=0.55、公平赔率、f\*=10%，8000 路径 × 600 注）：

| 下注比例 | 每注期望对数增长 | 600 注中位最大回撤 | 5% 分位终值 |
|---|---|---|---|
| 0.5×Kelly | +0.00375 | **55.4%** | 1.28x |
| 1.0×Kelly | +0.00501 | **84.5%** | 0.30x |
| 1.5×Kelly | +0.00374 | — | — |
| **2.0×Kelly** | **-0.00014（负）** | — | — |

**收益曲线在凯利点附近是平的，回撤曲线是陡的。多下注只多受罪，2 倍就转负。**
→ 实盘用 1/4–1/2 凯利；胜率估计误差 ±5% 就足以让 2× 变负。

## 三、回撤：不是止损能控的

子 agent 自算（GBM、10 年、σ=15%）：

| 真实 Sharpe | 10 年中位 MDD | 95 分位 MDD |
|---|---|---|
| 0.3 | 34.5% | 56.0% |
| 0.5 | 30.1% | 49.3% |
| 1.0 | 23.1% | 36.0% |
| 2.0 | 15.8% | 23.8% |

**想 MDD ≤20%，需要 Sharpe ≥1.5 且波动 ≤12%。**
→ **回撤预算 → 目标波动 → 仓位倒推**。"止损"替代不了事前仓位——跌停时止损失效。

## 四、失败案例（数字都具体到吓人）

| 事件 | 关键数字 | 教训 |
|---|---|---|
| **2007 量化地震** | 一周内顶级市场中性基金 -5% ~ -30%；标普 -3% 那天"中性"继续亏 | 危机中相关性→1；**"中性"≠无风险**；杠杆是唯一真正的风险源 |
| **LTCM 1998** | 资产 $129B / 资本 $4.7B = **28:1**；不到 4 个月亏 $4.6B | 25 倍杠杆下 **4% 不利变动 = 资本归零** |
| **Volmageddon 2018-02-05** | VIX 17.31→37.32（**+115%**，史上最大单日涨幅）；XIV 单日 **-96%** 并终止 | 反向波动率 ETN 有"单日 -80% 强制清算"条款——**结构本身保证你在最低点被平仓** |
| **Knight Capital 2012** | 部署残留代码，45 分钟发数百万笔错单，亏 **$440M**（≈2011 全年净利润 4 倍） | 上线清单：版本校验、单票/单日上限、kill switch；新代码首日只用 1–5% 资金 |
| **2024 A股微盘** | 2/5 中证 2000 单日 -9.49%、年内 -32.76%；微盘股指数 -13.7%；千股跌停；量化指增单周 -10%~-17% | 小市值+高换手+杠杆中性 = **同一笔拥挤交易**；规模是 alpha 的敌人 |
| **加密 2025-10-10** | 24 小时 **$19B** 杠杆仓位强平（史上最大），Hyperliquid 单日 $1.23B、6300 个钱包归零 | 交易所 = 交易对手 + 托管方；永续 ≥5x 在 -20% 插针中必被强平 |

## 五、策略衰减：默认假设，不是意外

- McLean-Pontiff：97 个因子样本外 **-26%**、发表后 **-58%**
- Falck/Rej/Thesmar：60 个策略发表后 Sharpe **约减半**；发表年份单独解释 30% 衰减方差
- **公开策略先打"样本外 ×0.5、发表后 ×0.4"折扣**

## 六、LLM/Agent 做交易的七种故障模式

1. **前视偏差（最致命）**：训练语料含未来信息；LAP 指标在训练截止前为正、截止后归零——回测里像"预测"，实盘里什么都不记得。
2. **数据泄漏**：新闻时间戳、复权价、财报修订值、退市股（survivorship）。
3. **非确定性**：同一 prompt 不同 run 结论不同 → 无复现、无归因。
4. **执行延迟**：单次调用 1–3 秒，多 agent 辩论到分钟级 → **只能日频以上**。
5. **幻觉**：财务数字、代码、API 字段都可能编造，必须在代码层校验。
6. **成本误判**：按收盘价成交写回测，真实成交在 T+1 开盘或更差，每年差 5–20%。
7. **过拟合新形态**：用 LLM 在历史上"找规律" = 超高维搜索机，必须配 DSR/样本外切分。

## 七、如果只记五条风控规则

1. **先算成本再算收益**：净 Sharpe = 毛 Sharpe − 换手×单边成本。扣不掉 30 倍换手的策略直接否，不讨论信号。
2. **仓位由"能承受的回撤"倒推**，不由"看好的程度"决定。
3. **杠杆上限写死**：散户 ≤1x，专业 ≤2x；单笔风险 ≤净值 0.5–1%。记住 LTCM 的 28:1。
4. **假设危机中相关性=1**，分散要跨资产/策略/交易所/托管。
5. **规则事前写死、自动执行**：降杠杆阶梯（-10% 降半、-20% 停手）+ 策略失效开关（回撤 >2 倍历史最大或 6 个月无超额 → 降半仓）。

## 八、新手最容易忽略的三个成本项

1. **最低佣金 5 元**：单笔 1 万元时实际 5bp，名义只有 2.5bp——翻倍，且完全可避免。
2. **价差与冲击**：A 股一次往返 15bp（小额）到 50bp+（90 万级）；回测按收盘价成交等于每年白送 5–20%。
3. **持有型成本**：永续资金费 11%/年、股指期货贴水 10–11%/年、融资利息——**不进"手续费"科目，直接从净值里扣**。

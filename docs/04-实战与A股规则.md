# 04 · 实战与 A 股规则

> 来源：子 agent 调研（🔁二手）。法规类条目可信度高，业绩类基本不可验证。
> **这一章是我们回测最容易出错、也最容易被忽略的部分。**

## 一、A 股实务规则（📄法规级）

| 项 | 规则 | 对回测的影响 |
|---|---|---|
| 印花税 | 卖出单边 **0.05%**（2023-08-28 减半），买入不收，ETF 免 | 高频策略硬成本 |
| 过户费 | 0.001% 双向 | 可忽略但要有 |
| 佣金 | 名义万 2.5，**单笔最低 5 元**，上限 3‰ | 小资金成本翻倍 |
| 涨跌幅 | 主板 10%（ST 也改 10%）、创业板/科创板 20%、北交所 30%，新股前 5 日不限 | **"跌停买入"基本是假的** |
| T+1 | 股票 T+1；**债券/货币/黄金/跨境 ETF 可 T+0** | 想做日内先确认品种 |
| 融资 | 默认 8.35%，实际 3.8–5.8%，百万级约 2.8% | 杠杆成本常被忽略 |
| 融券 | 2024-07-11 起暂停转融券；保证金 100%（私募 120%） | "对冲"没那么容易 |
| 股指期货 | 保证金 12%（期货公司加到 14–18%），**平今手续费是开仓的 10 倍** | 高频对冲成本极高 |
| 期货贴水 | IC/IM 年化贴水 **6–11%** | 中性策略的真实门槛 |
| 价格笼子 | 沪市限价单须在基准价 **±2%** 内；满仓市价单按涨停价冻结资金 | 大单执行会失败 |

**一句话：我们之前回测用的"8bp 双边"低估了现实。** 真实往返约 15bp（小额）到 50bp+（大额），且跌停时根本卖不掉。

## 三、看起来能赚、其实不能的模式

| 模式 | 真相 |
|---|---|
| 网格 | 单边下跌穿区间后"越跌越买"变满仓被套；A 股 T+1，日内网格只能靠底仓或 T+0 ETF |
| 马丁/加仓摊平 | **负凸性**：长期小赚、一次归零 |
| 散户高频/日内 T+0 | 佣金最低 5 元 + 卖出印花税 0.05%，已吃掉大部分价差；没托管没 colo |
| 小市值/微盘无脑轮动 | 2017 年跑输沪深300 近 26pp；2024-02 微盘指数年内 **-40.09%** |
| 双均线/海龟直套 A 股 | T+1 + 涨跌停让信号常无法执行，教程只截顺势那段 |
| "吃贴水"当无风险 | 贴水 6–11% 是真的，但基差会反向、保证金会不够；2024-02 DMA 2–4 倍杠杆就这么爆的 |
| 策略商城/跟单 | 只给持仓不给逻辑，无法判断是否过拟合 |
| "AI 全自动躺赚"软件 | 模拟实盘系统 25 元/周起售，战绩可完全由软件生成 |

## 四、从业者反复强调、教程里不写的事

1. **先回答"谁在亏钱给你"**。说不清对手盘，参数优化只是在拟合噪声。A 股很多"有效因子"是散户结构 + 涨跌停制度的产物，制度一变就失效。
2. **成本按"印花税 + 最低佣金 5 元 + 冲击"算**，不是按万三算。小资金做高频，在成本表上就已经死了。
3. **试验次数是必须披露的隐藏参数**。看到"年化 X%"先问：试了多少版、样本外是哪几年、扣成本后剩多少。
4. **回测到成交隔着交易所和柜台两层现实**：一字涨跌停买不进卖不出、停牌、ST 名单、±2% 价格笼子、11:30 的单直接送柜台。
5. **杠杆和拥挤度决定你能不能活到均值回归**。同一套 alpha，杠杆一加就从"回撤"变成"清盘"。

## 五、三条中文互联网上不可信的赚钱说法

1. "回测年化 100%、回撤 15%，AI 全自动躺赚" —— 通常同时踩未来函数、成交幻觉、几百版里挑最好的一版。
2. "跟着大V实盘抄作业 / 定投十年十倍" —— 雪球组合默认是模拟盘；口号与记录差得很远。
3. "网格/马丁/外汇 EA 月化 5–10%、回撤很小" —— 网格在单边下跌里满仓被套，马丁负凸性一次归零；境外 CFD 不受中国法律保护。

## 六、对我们自己的直接修正

| 我们之前的假设 | 修正 |
|---|---|
| A 股 ETF 往返 8bp | 单边 8bp = **往返 16bp**，与"小额往返约 15bp"基本吻合；大额（90 万级）往返可到 50bp+ |
| 跌停也能按收盘价成交 | 不能，必须建模"跌停不可买/不可卖" |
| 换手 977%/年 → 8bp 吃掉 0.78pp | 算术复核：977% × 0.08% ≈ **0.78pp/年**；按单边 15bp 则 977% × 0.15% ≈ **1.47pp/年** |

**更正说明（2026-11-16）**：本文件初稿写"按 15bp 要耗 14.7pp/年"，是**小数点错了一位**，实际约 1.5pp。已改。

**由此引出一个必须复核的问题**：如果换手成本只有 1.5pp/年，那么此前"成本从 8bp 提到 20bp，组合年化从 +3.96% 掉到 -1.24%"的说法**在算术上对不上**（差异应有约 1.2pp，而不是 5.2pp）。
可能原因：旧脚本对加密仓位按 25bp 计、或对权重变化重复计费。**这是一处待复核的计算缺陷，在澄清之前，任何基于"高成本"的结论都不可引用。**

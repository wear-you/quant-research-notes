# 私有金融知识库 · 索引

> 建立于 2026-11-16。目标：把公开分享里**缺失的、被夸大的、以及我们自己实测的**东西合到一起，
> 形成一个别人没有的知识库。
>
> 规则：**每条结论必须带证据等级**。「别人说」「我看到」「我跑过」是三种完全不同的东西。

## 证据等级定义

| 等级 | 含义 | 标记 |
|---|---|---|
| A | 我自己在本机跑过、可复现 | ✅实测 |
| B | 一手来源可查（官方文档、论文原文、GitHub API） | 📄一手 |
| C | 二手转述，来源可信但未核原文 | 🔁二手 |
| D | 流传广但没有来源，或已知有商业动机 | ⚠️存疑 |
| X | 已被我们的实验证伪 | ❌证伪 |

## 本库的三条独有价值（别人没有的）

1. **负结果**：我们亲手证伪了 90 日动量、横截面动量、A 股趋势择时、A 股波动率目标。公开分享里几乎没人写"我试过，不行"。
2. **样本扩容导致结论翻转的完整记录**：3 个币 → 13 个币，夏普从 0.97 掉到 0.74。这是「小样本幻觉」的第一手标本。
3. **成本敏感性的量化**：A 股策略在 8bp→20bp 之间由正转负，换手率 977%/年。这个数很少有人公开。

## 使用方式

- 想快速判断一条说法可不可信 → 查它的证据等级

- 想避开已死的路 → `06-我们自己的实证.md`（**先看这个，省时间**）
- 想找还没人做的方向 → `07-空白与机会.md`

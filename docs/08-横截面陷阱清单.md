# A股横截面研究：特殊陷阱与实证清单

**证据等级**：A=同行评议论文（注样本期）｜B=交易所规则/可复现工程｜C=社区传言（未验证）｜✅=本机实测

## 1 幸存者偏差：用今天的沪深300回溯
- ✅ 当前300只中仅**50.3%**在2010-01-01前上市（中位上市日2009-12-11）。2010年起的回测，一半标的当时还不存在——这是前视，不只是幸存。
- ✅ 全程在市（2015-01起）的206只当前成分股，年化收益**中位数7.5%**，同期沪深300全收益3.3%/年，**69%跑赢指数**。选样红利≈4pp/年。
- B 指数半年调样：2024-12更换16只（5.3%）；退市2015-21年≤23家/年，2022-24年46/45/52家。
- **做法**：①池子取"当日全市场快照"（含停牌、ST、退市整理），不用今天成分股；②按中证公告生效日重建 point-in-time 成分（akshare只给当前名单）；③退市股用 `stock_info_sh_delist`/`sz_delist` 补回，按退市整理期真实跌幅结算；④报告必须写"池子是哪一天的"。

## 2 交易制度约束
| 约束 | 规则 | 回测必须做 |
|---|---|---|
| 涨跌停 | 主板10%；创业板/科创板20%；北交所30%；主板ST 5%（双创ST仍20%）；新股前5日不限 | 封板=不可成交，禁止按收盘价成交；涨停买、跌停卖判失败 |
| T+1 | 当日买入次日才能卖 | t日信号→t+1成交；当日止损无效 |
| 停牌 | 重组停牌≤10个交易日，复牌常补跌 | 停牌期不计收益、不可调仓，复牌按开盘价 |
| 最小单位 | 主板/创业板100股整数倍；科创板200股起、1股递增 | 整手取整，小资金权重偏离大 |
| ST | 主板5%、双创20%；不进两融标的 | 按日维护ST名单；禁止用"后来摘帽"筛股 |
| 价格笼子 | 连续竞价限价单±2% | 涨跌停附近大单会废单 |

## 3 成本结构（双边）
佣金万2.5、**单笔最低5元**（双向）；印花税**0.05%卖出**（2023-08-28减半）；过户费0.001%双向（2022-04-29起）；经手费0.00341%双向。
→ 冲击成本按订单/日均成交额：<1%ADV约0.05–0.1%，5–10%ADV约0.3–0.5%。
→ 现实往返：大盘低换手**0.16–0.25%**；小盘高换手**0.3–0.6%**。
→ 5元最低佣金是隐形杀手：单笔5000元时佣金0.1%/边，是名义万2.5的4倍；10万资金持20只，开局就比大账户多付约0.2%。

## 4 复权与分红
- **前复权**：历史价随每次分红被重写，同一脚本不同时点跑出不同历史；长历史高分红股可能负价；价格类因子（低价股、整数关口）失真。
- **后复权**：基准固定，适合算收益；价格水平无经济含义，不能用于"股价<10元"筛选。
- **不复权**：除权日跳空（10送10即-50%），制造假暴跌与假反转。
- **正确口径**：收益用后复权/全收益；市值=不复权价×总股本（股本变动同步）；换手率用原始成交量；现金分红按除息日再投资（红利税：持股>1年免、1月–1年10%、<1月20%）。

## 6 动量为何与美股相反
- 美股：Jegadeesh-Titman 1993，12-1动量约1%/月（A）。
- A股：月度动量不显著（高秋明等2014，1994-2011；LSY 2019，2000-2016）；只有2-4周形成/1-3周持有有稳定动量（A）。
- 机制：**T+1的隔夜折价**。日内动量与隔夜动量符号相反、互相抵消（白颢睿、吴辉航、柯岩，《财经研究》2020, 46(4):140-154）；MOM(12,1,1)在市场高波动月**-1.33%**、低波动月**+1.27%**（A）。
- 结论：月度动量因子在A股≈噪声；短线用1M反转+换手率，别照搬美股。

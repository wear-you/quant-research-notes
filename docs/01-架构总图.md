# 01 · 架构总图

> 六层架构。每层标出「成熟方案」「我们的现状」「能不能自己搞」。
> 原则：**先找断点，再看方案。** 断点就是机会所在。

## 全图

```
┌─────────────────────────────────────────────────────────┐
│ 6  认知层  为什么做这件事：目标、约束、风险偏好              │  ← 最容易被忽略，却决定一切
├─────────────────────────────────────────────────────────┤
│ 5  执行层  下单、券商接口、撮合、滑点                       │  ← 硬约束：需要账户 + 本金
├─────────────────────────────────────────────────────────┤
│ 4  风控层  仓位、回撤约束、相关性、尾部风险                  │
├─────────────────────────────────────────────────────────┤
│ 3  决策层  Agent 编排、信号合成、多模型投票                  │
├─────────────────────────────────────────────────────────┤
│ 2  研究层  因子、模型、回测、过拟合检验                      │  ← 最大的技术短板
├─────────────────────────────────────────────────────────┤
│ 1  数据层  行情、基本面、另类数据、数据质量                   │  ← 我们刚补齐
└─────────────────────────────────────────────────────────┘
```

## 逐层状态

| 层 | 成熟方案 | 我们的现状 | 自己能做吗 |
|---|---|---|---|
| 1 数据 | akshare、OpenBB、yfinance | ✅ 33 个序列，最长 35 年（上证综指 1990 起） | 已做 |
| 2 研究 | Qlib、ML4T、RD-Agent | ⚠️ 只有 200MA + 波动率目标 + 自己做的手工回测 | 部分能，缺因子库 |
| 3 决策 | TradingAgents、FinRobot、ai-hedge-fund | ❌ 无多智能体，靠我单模型推理 | 能，但收益未知 |
| 4 风控 | PyPortfolioOpt、quantstats | ⚠️ 等权 + 手工算指标 | 能 |
| 5 执行 | Lean、vnpy、freqtrade、Lumibot | ❌ 完全没有 | **不能（无账户/本金）** |
| 6 认知 | 无标准答案 | ✅ 有明确目标与约束 | 必须自建 |

## 关键判断：断点在哪

**第 5 层是硬断点，第 2 层是软断点。**

- 硬断点（执行）：没有证券账户和本金，任何"下单"方案都是空谈。这不是技术问题，是身份与资金问题。
- 软断点（研究）：因子库、过拟合检验、组合优化，这些**不需要钱就能做**，而且决定了一个策略是真是假。

**所以我们的运营位只能是 1 / 2 / 4 / 6 层——即「研究 + 风控 + 认知」，把执行层留空。**
这不是妥协，是当下唯一没有幻觉的定位。

## 第 6 层：认知层（我们真正的主场）

这一层公开讨论最少，因为它不可复用。但它决定前五层的意义。

我们的既有约束（已写入 `profile.md`）：

| 约束 | 值 | 推论 |
|---|---|---|
| 本金 | ¥0 | 不能做任何需要钱的策略 |
| 账户 | 无 | 不能实盘，只能纸面 |
| 收款通道 | 无 | 输出无法直接变现 |
| 时间 | Agent 7×24，用户每天 10–30 分钟 | 研究可以连续，执行不能 |
| 可公开身份 | GitHub `wear-you` | 唯一分发面 |

**由此推出唯一合理的战略：把「研究与负结果」本身做成资产，而不是把「交易收益」做成资产。**

## 这个架构下的产品形态（三选一）

| 形态 | 依赖 | 可行性 |
|---|---|---|
| A. 方法论文档 + 负结果库（开源） | GitHub 分发 | ✅ 今天就能做 |
| B. 策略复现与审计服务（帮别人验策略真假） | 需要口碑 | 中期 |
| C. 实盘管理 | 账户 + 本金 + 资质 | ❌ 现在不行 |

**A 是 B 的入场券。C 在拿到 A/B 的信任之前不可能。**

## 与公开框架的关系

TradingAgents（122k★）是第 3 层的完整实现，但它是**研究框架，不产出收益**。
Qlib（50k★）是第 2 层的完整实现。
两者的共同点：**都不解决第 5 层**。

这意味着：**照抄它们不会让我们赚钱，只会让我们更像它们——而它们也不赚钱。**

真正缺的不是架构，是**在第 2/6 层做出别人没有的东西**。我们已有的候选：负结果库、样本扩容翻转记录、成本敏感性量化。

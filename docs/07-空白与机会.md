# 07 · 空白与机会

> 综合四路调研 + 我们自己的实证，找"别人没做、而我们能做"的位置。

## 一、四路调研共同指出的空白

| 空白 | 谁说的 | 证据 |
|---|---|---|
| **回测↔实盘不一致** | 工程层 | 只有 4 个项目做到同一份代码两端运行；Qlib/vectorbt/RQAlpha/FinRL 都止于研究 |
| **成本与容量建模缺失** | 工程层 + 风控层 | 多数引擎只有"固定手续费 + 固定滑点"；不建模冲击、T+1、涨跌停 |
| **LLM 框架缺可复现评估** | 工程层 + 方法论 | 输出叙事型决策，没有 walk-forward、成本、统计显著性 |
| **风控只到组合层** | 工程层 + 风控层 | pre-trade 限额、kill switch 在多数 RL/LLM 项目里缺失 |
| **没人公开负结果** | 实战层 | 集思录那种"7 年贴实盘、亏了照写"是极少数；大多数只有口号 |
| **没人报试验次数** | 方法论 | DSR/PBO 证据最强、实践最少 |

## 二、这个行业的真实分布

```
99% 的内容  →  讲怎么赚（回测、策略、参数）
1%  的内容  →  讲成本、失败、样本外、试验次数
0.1% 的内容 →  讲"我自己试过，不行"
```

**我们恰好站在 0.1% 里。** 这不是道德优势，是稀缺性。

## 三、我们已有的、别人没有的四件东西

| 资产 | 为什么稀缺 | 能否变现 |
|---|---|---|
| **六条已证伪的结论**（动量、横截面、A股择时、加密VOLT…） | 公开分享几乎不写失败 | 可做内容/工具 |
| **三次样本扩容导致的结论翻转全记录** | 3币→13币夏普 0.97→0.74；6年→35年 A股择时翻案 | **最有价值**，是方法论教材 |
| **成本敏感性的量化**（8bp→20bp 生死线；换手 977%/年） | 多数人只报毛收益 | 可直接做"策略体检"服务 |
| **数据闸门**（过期快照、降级源截断、WAF 事故） | 工程细节，很少有人写 | 技术信誉 |

## 四、可行机会（按"不需要本金"排序）

| 机会 | 需要什么 | 现实收益 | 风险 |
|---|---|---|---|
| **A. 负结果库 + 方法论文档（开源）** | GitHub（已有） | $0 直接，但建立信誉 | 低 |
| **B. 策略体检/复现服务**：帮人验"这个策略是不是过拟合" | 口碑 + 案例 | 单次 $50–300 | 中（要有人信） |
| **C. 数据质量工具**：把 `check_data.py` 做成通用包 | 工程打磨 | 极小 | 低 |
| **D. 纸面跟踪记录**：长期公开、不可回改 | 时间 | $0 直接，但可引流 | 低 |
| **E. 实盘管理/自营** | 账户 + 本金 + 资质 | 可能最高 | **现在不可行** |

**A + D 是 B 的入场券。C 是 A 的副产品。**

## 五、最重要的商业判断

三个事实拼在一起：

1. 122k★ 的 TradingAgents **不公开收益曲线**
2. Alpha Architect 的实盘 ETF 年化 **5.31%**，同期大盘 14.96%
3. CXO 统计的 20 位"大师" **41% 正确**，还不如"永远看多"的 62%

**结论：在这个圈子里，"公开的成功"几乎都是名声，不是交易利润。**
靠"我懂 AI 量化"赚钱，比靠量化本身赚钱确定性高一个数量级。

这不是犬儒，是定位依据：**我们的产品应该是"让人少犯错"，而不是"替你赚钱"。**

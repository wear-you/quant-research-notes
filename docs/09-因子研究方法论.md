# 横截面因子研究方法论 — 可执行规范

适用：沪深300 成分股日频面板，numpy/pandas，无 sklearn。
目标：从「预测个股方向」转向「横截面排序（ranking）」。

证据标签：**[强]** 论文/权威教材有明确统计证据；**[经验]** 业界共识/社区实践，缺严格检验。

## 0. 数据与标签（先做对，再谈因子）

| 项 | 规范 |
|---|---|
| 股票池 | **point-in-time** 沪深300 历史成分表，按调整生效日切换（每年 6/12 月）。不得用当前成分回溯 |
| 可交易过滤 | 剔除 ST、停牌日、上市 < 60 日、当日涨跌停（主板 ±10%、双创 ±20%）无法成交的样本 |
| 因子时点 | f(i,t) 只能用 t 日收盘**及之前**可得信息 |
| 财务因子 | 按**公告日 ann_date** 对齐，不是报告期 report_period。年报/一季报 4/30、半年报 8/31、三季报 10/31 前不可用 **[强]** |
| 标签 | r(i,t→t+H) 后复权收益，H = 调仓周期，前后一致 |

> 最常见的隐性前视：`merge` 财务表时用 `报告期` 而不是 `公告日`。仅此一项就能把 IC 抬高 2–5 倍。

## 1. IC（信息系数）

### 1.1 定义与计算

- **Pearson IC**：`IC_t = corr_cs(f_i,t , r_i,t+1)`，对极端值极敏感。
- **Rank IC（Spearman）**：`RankIC_t = corr_cs(rank(f_i,t), rank(r_i,t+1))`，**横截面研究首选** **[强]**（对单调变换不变，抗肥尾）。

```python
def ic_series(f, r_fwd, min_n=100, method="rank"):
    out = {}
    for t in f.index:
        x, y = f.loc[t], r_fwd.loc[t]
        m = x.notna() & y.notna()
        if m.sum() < min_n:
            continue
        if method == "rank":
            x, y = x[m].rank(pct=True), y[m].rank(pct=True)
        else:
            x, y = x[m], y[m]
        out[t] = x.corr(y)          # Pearson on ranks == Spearman
    return pd.Series(out)
```

### 1.2 聚合：ICIR 与 t 值

```
ICIR      = mean(IC_t) / std(IC_t)          # 日频
年化ICIR  = ICIR * sqrt(252 / H)            # H = 预测期（交易日）
```

**关键**：重叠标签（H>1 且逐日计算）会让 IC 序列自相关，`std` 被低估。t 值必须用 Newey-West：

```
t_NW = mean(IC) / sqrt( NW_var(IC, lag=H-1) / T )
```

**门槛（A 股日频因子，H=5~20）**：

| 指标 | 及格线 | 备注 |
|---|---|---|
| \|mean RankIC\| | ≥ 0.03 | <0.02 基本是噪声 **[经验]** |
| 年化 ICIR | ≥ 0.5 可用 / ≥ 1.0 强 | **[经验]**，但需与 t 值一致 |
| NW t 值 | ≥ 3.0 | **[强]** HLZ |
| IC 胜率 | ≥ 55% | 辅助，防单期极端值主导 |

**容量自检 [强]**（Grinold 1989；Grinold & Kahn 2000，FLAM）：
`IR ≈ IC × sqrt(BR)`，`BR_eff = N / (1 + (N-1)·ρ̄)`。
N=300、个股残差相关 ρ̄≈0.2 → BR_eff≈5；IC=0.05 → IR≈0.11。
用 `IC×sqrt(300×252)` 算出来的 IR 是幻觉。

## 2. 分层回测（decile / quintile spread）

### 2.1 前置：中性化

```
z_t = resid( f_t ~ 1 + 行业哑变量 + ln(市值) )   # OLS 残差
z_t = (z_t - mean) / std                          # 再标准化
```
行业内标准化也行：`z = groupby(industry).transform(lambda s: (s-s.mean())/s.std())`，然后全样本再 z-score 一次。

### 2.2 分组与组合

```python
for t in rebalance_dates:
    z = neutralize(f.loc[t]).dropna()
    # 并列值会破坏 qcut，先按 rank(method='first') 打破
    q = pd.qcut(z.rank(method="first"), 10, labels=False)
    for g in range(10):
        idx = q[q == g].index
        w = pd.Series(1/len(idx), index=idx)          # 等权
        # w = mv[idx] / mv[idx].sum()                  # 市值加权
        ret[g] = (w * r_fwd.loc[t, idx]).sum()
    ls[t] = ret[9] - ret[0]        # 多空
    lo[t] = ret[9] - bench_ret[t]  # 纯多头超额（更贴近实盘）
```

### 2.3 规范要点

| 项 | 做法 | 证据 |
|---|---|---|
| 分组数 | 样本 ≥200 用 10 组；100–200 用 5 组；<100 不做分层 | [经验] |
| 边界 | 用**当日横截面分位点**，不允许同值跨组；用 rank 打破并列 | [强]（同值处理影响分组纯净度） |
| 等权 vs 市值加权 | **两者都报**。差异 >50% 说明因子在小/大盘上暴露不同，必须先市值中性 | [经验] |
| 多空构造 | 多顶 10%、空底 10%，等**金额**（beta≈0）；再叠加行业中性版本（行业内排序选股） | [强] |
| 必报指标 | 各组年化收益 + 单调性 `Spearman(组序, 组收益) ≥ 0.8`、多空年化/Sharpe/MaxDD、NW t、换手、行业暴露 | [经验] |
| A 股约束 | 空头不可执行 → 多空只作**信号强度诊断**，实盘看 `多头 − 基准` | [强]（制度约束） |

> 只看多空 Sharpe 不看单调性，是把「两个极端组的偶然差异」当成因子。

## 3. 换手率与调仓频率

### 3.1 IC 衰减曲线

对 H ∈ {1,2,3,5,10,20,40,60}，用**非重叠**采样算 `IC(H)`（避免重叠导致的伪衰减/伪平稳），画 `IC(H)/IC(1)`。

- IC 半衰期 = `IC(H) ≈ 0.5·IC(1)` 的 H，作为持有期**上限** [经验]。
- 若 `IC(H)` 在 H>20 后转负，说明信号是短期反转，不要长持。

### 3.2 持有期选择（可直接跑）

```
for H in candidates:                      # 5,10,20,40,60
    spread = mean(LS_ret_H)               # 每期多空收益
    gross  = (252/H) * spread
    cost   = (252/H) * TO(H) * c          # c = 单边成本率
    IR_net = (gross - cost) / (std(LS_ret_H) * sqrt(252/H))
H* = argmax IR_net,  s.t. IC(H*) ≥ 0.5*IC(1) 且 TO(H*) ≤ 0.5
```

### 3.3 成本参数（沪深300）

| 项 | 数值 |
|---|---|
| 佣金 | ~2.5bp 双边（万 2.5） |
| 印花税 | 5bp，**仅卖出**（2023-08-28 起减半） **[强]** |
| 经手费+过户费 | ~1bp |
| 冲击成本 | 5–15bp（300 大盘股）；小盘/高波动 20–40bp |
| **合计 c（单边）** | **≈10bp**；保守用 15bp；敏感性测试用 20bp |

**换手经验值 [经验]**：日频因子单边日换手 5–15%；H=20 时每次调仓单边换手 30–60%；月换手 >80% 的因子，多数 alpha 被成本吃掉。
**强证据**：Novy-Marx & Velikov (2016, RFS)《A Taxonomy of Anomalies and Their Trading Costs》——扣成本后大量异象消失，且与换手率高度相关。

## 4. 多重检验

### 4.1 Harvey-Liu-Zhu 门槛 [强]

Harvey, Liu & Zhu (2016), *…and the Cross-Section of Expected Returns*, RFS 29(1):5–68：
因学术界已检验数百个因子，**新因子 t > 3.0**（单侧，≈p<0.0027）才可称发现；t=2.0 不足。因子越多、相关性越高，门槛越高（Bonferroni / BHY）。同时给出 Sharpe 的 haircut：t≈2 时约砍 50%。

### 4.2 Deflated Sharpe Ratio [强]

Bailey & López de Prado (2014), *The Deflated Sharpe Ratio*, JPM 40(5):94–107。

```
SR0 = sqrt(V[SR_n]) * [ (1-γ)·Z⁻¹(1-1/N) + γ·Z⁻¹(1-1/(N·e)) ]      γ = 0.5772
DSR = Z{ (SR - SR0)·sqrt(T-1) / sqrt(1 + 0.5·SR² - γ3·SR + ((γ4-3)/4)·SR²) }
```
- N = **你真实做过的全部试验数**（含失败的、含调参网格），不是「最后报告的几个」。
- 判据：`DSR > 0.95`。SR 与 T 需用**同一频率**（日频年化要换算）。
- 你必须记试验日志，否则 DSR 无法计算——这本身就是纪律。

### 4.3 Purged K-Fold + Embargo [强]

López de Prado, *Advances in Financial Machine Learning* (2018), ch.7。

1. **Purging**：训练样本 i 若其标签区间 `[t_i, t_i+H]` 与测试折 `[t0,t1]` 有交集 → **删除**。
2. **Embargo**：测试折结束后再剔除 **1% 的样本**（≈5–20 个交易日），阻断序列相关泄漏。
3. 优先 **CPCV**（组合 purged CV，多条回测路径）；**禁止** 随机 KFold / 简单 shuffle。

```python
def purged_split(dates, test_start, test_end, H, embargo_frac=0.01):
    t0, t1 = idx[test_start], idx[test_end]
    emb = int(len(dates) * embargo_frac)
    train = [i for i in range(len(dates))
             if i + H < test_start or i > test_end + emb]   # 两侧都切
    return train, list(range(test_start, test_end + 1))
```

## 5. 常见错误清单

| # | 错误 | 后果 | 检查动作 |
|---|---|---|---|
| 1 | **前视偏差**：财务用报告期、用当日收盘后才知道的信息、用全样本均值标准化 | IC 虚高 2–5× | 全部按 ann_date；标准化只用**滚动/扩张窗口**的历史值 |
| 2 | **幸存者偏差**：用当前成分股回溯 | 年化虚高 2–4%/年 **[强]** | point-in-time 成分 + 退市股收益 |
| 3 | **样本内选参**：网格搜索后只报最优 | OOS 衰减 >50% | McLean & Pontiff (2016, JF)：样本外降 26%，**发表后降 58%** **[强]**；参数只许用 CV 内层选 |
| 4 | **忽略成本**：不扣成本、或只扣佣金 | 高换手因子归零 | 强制扣双边 20–30bp + 换手敏感性 |
| 5 | **未中性化**：行业/市值暴露未剥离 | 因子实为 beta/小市值 | 回归取残差；报告中性前后 IC 对比 |
| 6 | **重叠标签朴素 t 值** | t 虚高 1.5–3× | Newey-West，lag = H-1 |
| 7 | **不可交易样本**：涨跌停/停牌/一字板仍计入 | 虚高且不可复现 | 按成交可行性过滤 |
| 8 | **多次试验不记录** | 假阳性 | 试验日志 + DSR |
| 9 | **单一市场状态**：只测 2019–2021 牛市 | 过拟合 regime | 至少跨 2 轮牛熊，分年度 IC 稳定性 |
| 10 | **因子间共线**：把同一风格的 5 个变体当 5 个因子 | 虚假分散 | 相关 >0.7 视为同一因子，做正交化 |

## 6. 落地顺序（最小可行）

1. 建 PIT 股票池 + 公告日对齐表 → 数据审计（抽查 20 个财报日期）。
2. IC 引擎（Rank IC + NW t + 年化 ICIR）。
3. 中性化 + 十分组引擎（等权/市值加权双报）。
4. IC 衰减 → 选 H → 扣成本算 IR_net。
5. 试验日志 → DSR；CPCV 复核。
6. 只有同时满足 `|IC|≥0.03、年化ICIR≥0.5、NW t≥3、IR_net>0、DSR>0.95` 才进实盘候选。
